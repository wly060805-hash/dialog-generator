# 共情对话生成平台 (Dialogue Generator)

基于通义千问（Qwen）大模型的可控对话素材构建工具，供心理学共情实验的研究人员批量生成、筛选并导出虚拟人物对话。

## 功能

- **访问口令验证**：进入页面前需输入访问口令
- **双 Agent 流水线**：
  - **Agent 1（生成）**：按实验需求批量生成对话，内置程序化校验（轮数 / 发言完整性），不合格自动把问题反馈给模型 refine 重试（最多 3 次）
  - **Agent 2（评审）**：基于完整实验需求，从 5 个维度（主题契合度 / 角色性格一致性 / 对话风格符合度 / 共情激发潜力 / 结构与轮数合规性）独立打分，每项评分必须引用具体发言作为 evidence；总分由程序按维度重新求和，防止加总幻觉
  - **双评审共识（可选）**：开启后由两个不同模型独立评分，维度分取平均作为共识分；总分差超过阈值时标记「需人工复核」且不自动勾选
  - 两个 Agent 的模型可在设置中**分别选择**（建议不同模型以降低同源偏差）
- **预筛选与排名**：可设及格线（满分 50），评分后自动排名、自动勾选 PASS 对话，支持"仅显示通过"过滤
- **实验参数配置**：对话轮数、对话主题、角色A/角色B 性格特点、对话风格、备注
- **批量生成**：一次生成 1~10 段候选对话（并发调用大模型），支持单段重新生成
- **对话预览**：聊天气泡形式展示每段对话 + Agent2 评审报告（维度分数条 + 依据 + 总评）
- **CSV 导出**：导出选中 / 全部 / 单段对话，含实验参数、排名、总分、各维度分数与评审依据，UTF-8 BOM 编码可直接用 Excel 打开

## 使用流程

1. 研究人员在表单中描述数据生成需求（轮数 / 主题 / 性格 / 风格 / 备注）
2. **Agent 1** 批量生成候选对话（自动校验 + refine）
3. **Agent 2** 对每段对话打分排名并给出 evidence（可生成后自动触发）
4. 研究人员按排名 / 及格线筛选，导出 CSV 用于后续实验

## 技术栈

React + TypeScript + Vite + Tailwind CSS，纯静态站点，可直接部署到 GitHub Pages。

## 本地开发

```bash
npm install
npm run dev      # 开发服务器 http://localhost:3000
npm run build    # 构建到 dist/
npm run preview  # 预览构建产物
```

## 使用说明

1. 输入访问口令进入系统。
2. 点击右上角「设置」，填入通义千问 API Key（阿里云百炼 DashScope），模型默认为 `qwen3.7-max`，可按需修改。API Key 仅保存在本地浏览器 localStorage 中，不会上传。
3. 填写实验参数（轮数、主题、双方性格、风格、备注、批量数量）。
4. 点击「批量生成对话」，等待生成完成后勾选满意的对话。
5. 点击「导出选中 CSV」下载文件。

## GitHub Pages 部署

仓库已包含 `.github/workflows/deploy.yml`，推送 `main` 分支后自动构建并部署。

首次部署需在仓库页面开启 Pages：

**Settings → Pages → Build and deployment → Source 选择 "GitHub Actions"**

部署完成后访问地址为 `https://<用户名>.github.io/<仓库名>/`。

> ⚠️ 注意：纯前端部署意味着浏览器会直接调用 DashScope 接口。请勿将 API Key 硬编码进代码仓库（本项目通过页面设置项注入，不会提交到 Git）。
